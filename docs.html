terebi / nimble Documentation

A high-performance immediate-mode UI framework for SDL2. Build layouts, manage focus, and handle text input with a modern widget-tree API.

Overview

nimble is a lightweight immediate-mode UI builder using SDL2 rendering primitives. It provides a widget tree API and event helpers for hover, click, focus, keyboard navigation, and text input.

Key Concepts

  • Widgets: Immutable layout nodes built each frame with event callbacks.
  • Widget styles: Define background, border, shadows, padding and more.
  • Navigation: Explicit and supports keyboard direction and tab order.
  • Text fields: Bind to strings and support cursor movement, selection, and clipboard.

Core Widget List

Layout Widgets

  • Column – Vertical layout
  • Row – Horizontal layout
  • Padding – Inner spacing
  • Expanded – Flex child
  • Stack – Layered children
  • Scaffold – Root container
  • Position – Absolute wrapper
  • SizedBox – Fixed spacing

Visual Widgets

  • RoundedBox – Styled container
  • Box – Simple rectangle
  • Center – Alignment wrapper
  • Opacity – Composite flattening
  • Clip – Rounded mask
  • Image / Svg – Asset rendering
  • Text / Icon – Typography
  • TextField / Toggle – Controls

Event / Callback API

Attach behavior to any widget using chaining methods:

  • OnHover: OnHover(id, duration, animFn, curveFn)
  • OnClick: OnClick(id, duration, cb, animFn, curveFn)
  • OnFocus: OnFocus(id, duration, animFn, curveFn)
  • OnKeyPress: OnKeyPress(key, cb, triggerClickFallback=false)
  • OnType: OnType(cb) - Triggers on string change
  • OnSubmit: OnSubmit(cb) - Triggers on Enter key
  • WithNav: WithNav(up, down, left, right, next, prev)

Core Structs

WidgetStyle

Visual configuration including radius, borderWidth, shadowBlur, and gradient overlays.

InputState

Global input tracking for mouseX/Y, mouseClicked, keyPressed, and SDL textInput strings.

TextFieldState

Manages cursorPosition, selectionAnchor, and clipboard interactions.

Common Layout Patterns

Centered Panel

return Center(
    RoundedBox({300, 220}, style,
        Padding({20,20}, Column(MainAxisAlignment::Start, CrossAxisAlignment::Stretch, 16, {
            Text("Title", font, {255,255,255,255}),
            Text("Subtitle", font, {175,175,175,255})
        }))));

Responsive Horizontal Menu

return Row(MainAxisAlignment::SpaceBetween, CrossAxisAlignment::Center, 24, {
    MenuItem("Home"),
    MenuItem("Search"),
    MenuItem("Settings")
}, ScrollBehavior::None, ScrollAxis::Horizontal);

TextField / Input Patterns

Text fields bind directly to a string and expose change callbacks. Nimble automatically handles selection and cursor logic.

Widget search = TextField("search_input", queryString, "Search…", {400, 44}, tfStyle)
    .OnSubmit([&](std::string value) { /* handle submit */ })
    .OnType([&](std::string value) { /* live update */ });

Focus and Navigation

Explicit wiring is recommended for keyboard accessibility:

Button("Prev").WithNav("", "next_id", "", ""),
Button("Next").WithNav("", "", "prev_id", "")

Focus is tracked via global IDs: g_FocusedWidgetId.

Building Custom Widgets

Custom controls are composed of existing widgets. For example, a virtual keyboard is just a Stack of RoundedBox keys inside a Position wrapper.

auto keyboard = onScreenKeyboard(width, fonts, currentText, "search_input", isVisible, [&]() {
    // enter action
});

return Stack({ mainScreen, Position(PositionType::Fixed, {0, height - 300}, keyboard)});

Summary

Nimble provides a flexible model for modern SDL2 applications, bridging the gap between low-level rendering and high-level UI composition with a focus on keyboard-driven navigation and robust text input.
