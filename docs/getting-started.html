Getting Started with Nimble

Requirements

  • C++17 or later compiler
  • SDL2 or SDL3 development libraries
  • CMake 3.10+ for building
  • TTF fonts for text rendering

Installation

Add Nimble as a submodule to your CMake project:

git submodule add https://github.com/your-org/nimble.git third_party/nimble

Or download the source and copy to your project.

CMake Integration

Add to your CMakeLists.txt:

add_subdirectory(third_party/nimble)
target_link_libraries(your_app nimble SDL2 SDL2_ttf)

Basic Application

Create your first Nimble application:

#include <nimble/application.h>
#include <nimble/widgets/text.h>

class MyApp : public Nimble::IApp {
public:
    Widget Build(int width, int height, float deltaTime) override {
        return Widgets::Text("Hello, World!", nullptr, {255, 255, 255, 255});
    }
};

int main() {
    Nimble::ApplicationConfig config;
    config.title = "My Nimble App";
    config.width = 800;
    config.height = 600;

    MyApp app;
    Nimble::Application application(config, app);
    return application.Initialize() ? application.Run() : -1;
}

Building

Build with CMake:

mkdir build
cd build
cmake ..
make
