Nimble UI Framework

A modern, high-performance C++ UI framework built on SDL. Create beautiful, responsive applications with a focus on developer experience and runtime efficiency.

Get Started Browse API

🚀 High Performance

Optimized rendering pipeline with minimal overhead. Built for games and real-time applications.

🎮 Game-Ready Input

Comprehensive input handling for keyboard, mouse, gamepad, and TV remote controls.

📱 Cross-Platform

Seamless deployment across desktop, mobile, and embedded platforms via SDL.

🎨 Modern Styling

Flexible theming system with animations, shadows, and custom visual effects.

🔧 Developer Friendly

Intuitive API with comprehensive debugging tools and clear documentation.

📦 Zero Dependencies

Only requires SDL2/3 and standard C++ libraries. No external UI frameworks.

Quick Example

Here's how simple it is to create a basic Nimble application:

#include <nimble/application.h>
#include <nimble/widgets/text.h>

int main() {
    Nimble::Application app("My App", 800, 600);

    auto textWidget = Widgets::Text("Hello, Nimble!", font, color);
    app.setRootWidget(textWidget);

    return app.run();
}
