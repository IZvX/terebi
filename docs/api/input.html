Input & Navigation API

Focus Management

Nimble provides comprehensive focus management for keyboard and gamepad navigation.

g_FocusedWidgetId

Global variable containing the currently focused widget ID.

std::string g_FocusedWidgetId;

Header: nimble/widget.h

g_NextFocusedWidgetId

Set this to change focus to a different widget.

std::string g_NextFocusedWidgetId;

Header: nimble/widget.h

Usage Example

// Focus a specific widget
g_NextFocusedWidgetId = "submit_button";

g_SecondaryFocusedWidgetId

Secondary focus for complex interactions.

std::string g_SecondaryFocusedWidgetId;

Header: nimble/widget.h

g_inputFocused

Indicates if a text input widget currently has focus.

bool g_inputFocused;

Header: nimble/widget.h

Navigation System

Widgets can be connected in navigation graphs for keyboard/gamepad traversal.

WidgetNav

Structure defining navigation links for a widget.

struct WidgetNav {
    std::string up = "";
    std::string down = "";
    std::string left = "";
    std::string right = "";
    std::string next = ""; // Tab
    std::string prev = ""; // Shift+Tab
};

Header: nimble/widget.h

g_NavigationLinks

Global map of widget navigation configurations.

std::unordered_map<std::string, WidgetNav> g_NavigationLinks;

Header: nimble/widget.h

ResolveNavTarget(startId, direction)

Finds the next widget in a given navigation direction.

std::string ResolveNavTarget(const std::string& startId, const std::string& direction);
Parameters
startId: Starting widget ID
direction: Navigation direction ("up", "down", "left", "right", "next", "prev")
Returns
Target widget ID or empty string if none found

Header: nimble/widget.h

Widget Modifiers

Methods to configure widget behavior and navigation.

WithNav(up, down, left, right, next, prev)

Configures navigation links for a widget.

Widget WithNav(std::string up, std::string down, std::string left, std::string right, std::string next = "", std::string prev = "");

Header: nimble/widget.h

Usage Example

auto button = Widgets::Text("OK", font, color)
    .WithNav("", "cancel_btn", "", "submit_btn", "submit_btn", "cancel_btn");

OnKeyPress(key, callback, triggerClickFallback)

Binds a key press to a callback function.

Widget OnKeyPress(SDL_Keycode key, std::function<void()> cb, bool triggerClickFallback = false);
Parameters
key: SDL keycode to bind
cb: Callback function
triggerClickFallback: Also trigger onClick if set

Header: nimble/widget.h

OnClick(callback)

Binds a click event to a callback function.

Widget OnClick(std::function<void()> cb);

Header: nimble/widget.h

Text Input Events

Specialized events for text field focus changes.

OnTextFieldFocus(callback)

Registers a callback for text field focus events.

void OnTextFieldFocus(std::function<void(const std::string&, bool)> callback);
Parameters
callback: Function called with (fieldId, focused)

Header: nimble/application.h

Internally fires text field focus events.

void FireTextFieldFocusEvent(const std::string& id, bool focused);
