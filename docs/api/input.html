Nimble provides comprehensive focus management for keyboard and gamepad navigation.

g_NextFocusedWidgetId = "submit_button";

Navigation System

Widgets can be connected in navigation graphs for keyboard/gamepad traversal.

NavAction

Logical navigation actions that can be triggered by any mapped input source.

enum class NavAction { Up, Down, Left, Right, Next, Prev, Back, Forward };

Header: nimble/application.h

Navigation Mapping

Maps physical inputs or app-provided signals to logical navigation actions. Default mappings keep the built-in behavior: arrow keys move by direction, Tab moves next, Shift+Tab moves previous, Esc or mouse back triggers Back, and F1 or mouse forward triggers Forward.

void ResetDefaultNavigationMappings();
void ClearNavigationMappings();
void MapNavigationKey(NavAction action, SDL_Keycode key, Uint16 requiredMod = 0, Uint16 rejectedMod = 0, const std::string& label = "");
void MapNavigationMouseButton(NavAction action, Uint8 mouseButton, const std::string& label = "");
void MapNavigationFlag(NavAction action, bool* flag, bool consume = true, const std::string& label = "");
void MapNavigationPredicate(NavAction action, std::function<bool(const InputState&)> predicate, const std::string& label = "");
void MapNavigationCallback(NavAction action, std::function<bool()> callback, const std::string& label = "");
void TriggerNavigationAction(NavAction action, const std::string& label = "");

Header: nimble/application.h

Usage Example

// Vim-style keyboard navigation plus default Tab behavior
Nimble::ClearNavigationMappings();
Nimble::MapNavigationKey(Nimble::NavAction::Left,  SDLK_h, 0, 0, "H");
Nimble::MapNavigationKey(Nimble::NavAction::Down,  SDLK_j, 0, 0, "J");
Nimble::MapNavigationKey(Nimble::NavAction::Up,    SDLK_k, 0, 0, "K");
Nimble::MapNavigationKey(Nimble::NavAction::Right, SDLK_l, 0, 0, "L");
Nimble::MapNavigationKey(Nimble::NavAction::Prev,  SDLK_TAB, KMOD_SHIFT, 0, "SHIFT+TAB");
Nimble::MapNavigationKey(Nimble::NavAction::Next,  SDLK_TAB, 0, KMOD_SHIFT, "TAB");

External Input Example

// Android, websocket, gamepad, or another thread can flip this flag.
static bool remoteNext = false;
Nimble::MapNavigationFlag(Nimble::NavAction::Next, &remoteNext);

// Or poll any custom input source.
Nimble::MapNavigationCallback(Nimble::NavAction::Up, [] {
    return MyRemoteController::Pressed("up");
}, "REMOTE_UP");

// Or queue a one-shot action directly from your bridge code.
Nimble::TriggerNavigationAction(Nimble::NavAction::Down, "REMOTE_DOWN");

OnNavigationAction(action, callback)

Registers a callback that fires whenever a logical navigation action is queued.

void OnNavigationAction(NavAction action, std::function<void()> callback);

Header: nimble/application.h

OnBack / OnForward

Registers application-level browser-style navigation handlers. Use these for route history, drawer dismissal, modal closing, or custom page stacks.

void OnBack(std::function<void()> callback);
void OnForward(std::function<void()> callback);

Header: nimble/application.h

Usage Example

Nimble::OnBack([] {
    if (ModalOpen()) CloseModal();
    else Router::Back();
});

Nimble::OnForward([] {
    Router::Forward();
});

WidgetNav

Structure defining navigation links for a widget.

struct WidgetNav {
    std::string up = "";
    std::string down = "";
    std::string left = "";
    std::string right = "";
    std::string next = ""; // Tab
    std::string prev = ""; // Shift+Tab
};

Header: nimble/widget.h

g_NavigationLinks

Global map of widget navigation configurations.

std::unordered_map<std::string, WidgetNav> g_NavigationLinks;

Header: nimble/widget.h

ResolveNavTarget(startId, direction)

Finds the next widget in a given navigation direction.

std::string ResolveNavTarget(const std::string& startId, const std::string& direction);
Parameters
startId: Starting widget ID
direction: Navigation direction ("up", "down", "left", "right", "next", "prev")
Returns
Target widget ID or empty string if none found

Header: nimble/widget.h
