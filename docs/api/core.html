Core API

Application Lifecycle

The core of any Nimble application is the Application class, which manages the SDL window, rendering loop, and widget hierarchy.

ApplicationConfig

Configuration structure for Application initialization.

struct ApplicationConfig {
    std::string title = "Nimble Application";
    int width = 1280;
    int height = 720;
    RendererBackend renderer = RendererBackend::SDL;
    Uint32 sdlWindowFlags = SDL_WINDOW_SHOWN | SDL_WINDOW_RESIZABLE;
    Uint32 sdlRendererFlags = SDL_RENDERER_ACCELERATED;
    bool enableVSync = true;
    bool enableGPU = false;
};
Members
title: Window title string
width/height: Window dimensions in pixels
renderer: Backend renderer type
sdlWindowFlags: SDL window creation flags
sdlRendererFlags: SDL renderer creation flags
enableVSync: Enable vertical sync
enableGPU: Enable GPU acceleration

Header: nimble/application.h

class Application

Main application class that manages the SDL window and rendering loop.

class Application {
public:
    Application(const ApplicationConfig& config, IApp& app);
    bool Initialize();
    int Run();
};
Methods
Application(config, app): Constructor taking configuration and app instance
Initialize(): Initialize SDL and create window
Run(): Start the main application loop

Header: nimble/application.h

Usage Example

ApplicationConfig config;
config.title = "My App";
config.width = 800;
config.height = 600;

MyApp app;
Application application(config, app);
if (application.Initialize()) {
    return application.Run();
}

class IApp

Interface that user applications must implement to provide the root widget.

class IApp {
public:
    virtual Widget Build(int width, int height, float deltaTime) = 0;
    virtual void OnStart() {}
};
Methods
Build(width, height, deltaTime): Called each frame to build the widget tree
OnStart(): Called once at application startup

Header: nimble/application.h

Init()

Initialize the Nimble framework. Must be called before creating any widgets.

void Init();

Header: nimble/application.h

Usage Example

int main() {
    Nimble::Init();
    // Now safe to create widgets
}

LoadFont(path, size)

Load a TTF font for use in text rendering.

TTF_Font* LoadFont(const std::string& path, int size);
Parameters
path: Path to the TTF font file
size: Font size in points
Returns
TTF_Font pointer, or nullptr on failure

Global State

Nimble maintains global state for focus management, navigation, and debugging.

g_FocusedWidgetId

Global variable containing the ID of the currently focused widget.

std::string g_FocusedWidgetId;

g_inputFocused

bool g_inputFocused;

Header: nimble/widget.h

Widget Inspector

Nimble includes a built-in inspector for live widget debugging. Press F12 to toggle it. When open, the application viewport is shrunk and shifted so the inspector sidebar does not cover the app.

Inspector APIs

The inspector lists rendered widgets, their IDs, guessed widget type, rect, child count, and live override controls for common visual/state values.

void ToggleWidgetInspector();
bool IsWidgetInspectorOpen();
