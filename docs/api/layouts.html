Layouts API

Overview

Layout widgets control how child widgets are positioned and sized. Nimble provides flexible layout containers that adapt to different screen sizes and content.

Row

Arranges children horizontally in a row with configurable alignment and spacing.

Widget Row(RowArgs args = {});

RowArgs:

PropertyTypeDescription
mainAlignMainAxisAlignmentHorizontal alignment of children
crossAlignCrossAxisAlignmentVertical alignment of children
spacingintSpace between children
childrenstd::vector<Widget>Child widgets to arrange
scrollScrollBehaviorScrolling behavior
axisScrollAxisScroll axis
idstd::stringWidget identifier
expandXfloatHorizontal expansion factor
expandYfloatVertical expansion factor
autoSetupNavboolAutomatically setup navigation

Header: nimble/widgets/row.cpp

Usage Example

auto row = Widgets::Row({
    .mainAlign = MainAxisAlignment::SpaceBetween,
    .crossAlign = CrossAxisAlignment::Center,
    .spacing = 20,
    .children = {icon, title, button}
});

Column

Arranges children vertically in a column with configurable alignment and spacing.

Widget Column(ColumnArgs args = {});

ColumnArgs has the same structure as RowArgs but arranges children vertically.

Header: nimble/widgets/column.cpp

Usage Example

auto column = Widgets::Column({
    .mainAlign = MainAxisAlignment::Start,
    .crossAlign = CrossAxisAlignment::Stretch,
    .spacing = 10,
    .children = {header, content, footer}
});

Stack

Stacks children on top of each other, allowing for layered layouts.

Widget Stack(std::vector<Widget> children);
Parameters
children: Vector of widgets to stack, rendered in order

Header: nimble/widgets/stack.cpp

Usage Example

auto stack = Widgets::Stack({
    Widgets::Image("background.jpg", {400, 300}),
    Widgets::Center(Widgets::Text("Overlay Text", font, color)),
    closeButton
});

Scaffold

Provides a basic app structure with background and content areas.

Widget Scaffold(std::vector<Widget> children, Widget background = {});
Parameters
children: Content widgets
background: Optional background widget

Header: nimble/widgets/scaffold.cpp

Padding

Adds space around a child widget.

Widget Padding(Vector2 padding, Widget child);
Parameters
padding: Padding amount as Vector2 (x, y)
child: Widget to pad

Header: nimble/widgets/padding.cpp

Usage Example

auto paddedButton = Widgets::Padding({10, 5}, button);

Center

Centers a child widget within the available space.

Widget Center(Widget child);

Header: nimble/widgets/center.cpp

Expanded

Expands to fill available space in flex layouts.

Widget Expanded(float flexX, float flexY, Widget child);
Parameters
flexX: Horizontal expansion factor
flexY: Vertical expansion factor
child: Widget to expand

Header: nimble/widgets/expanded.cpp

Alignment Enums

MainAxisAlignment

Controls alignment along the main axis (horizontal for Row, vertical for Column).

enum class MainAxisAlignment {
    Start,
    Center,
    End,
    SpaceBetween,
    SpaceAround,
    SpaceEvenly
};

CrossAxisAlignment

Controls alignment along the cross axis (vertical for Row, horizontal for Column).

enum class CrossAxisAlignment {
    Start,
    Center,
    End,
    Stretch
};
