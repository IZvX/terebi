Widgets API

Overview

Widgets are the building blocks of Nimble UI. Each widget is a self-contained UI component that handles its own rendering and interaction.

Text

Renders static text using a TTF font.

Widget Text(const std::string& text, TTF_Font* font, SDL_Color color, Gradient grad = {});
Parameters
text: The text string to render
font: TTF font pointer for rendering
color: Text color as SDL_Color
grad: Optional gradient effect
Returns
Widget instance configured for text rendering

Header: nimble/widgets/text.cpp

Usage Example

TTF_Font* font = Nimble::LoadFont("arial.ttf", 16);
auto textWidget = Widgets::Text("Hello World", font, {255, 255, 255, 255});

TextField

Interactive text input field with cursor and selection support.

Widget TextField(const std::string &id, std::string &text, const std::string &placeholder, Vector2 size, TextFieldStyle tfStyle);
Parameters
id: Unique identifier for the widget
text: Reference to string that will be modified by user input
placeholder: Placeholder text shown when field is empty
size: Widget dimensions
tfStyle: TextFieldStyle configuration
Returns
Widget instance with text input functionality

Header: nimble/widgets/text_field.cpp

Usage Example

std::string userInput;
TextFieldStyle style;
style.font = font;
style.textColor = {255, 255, 255, 255};
auto field = Widgets::TextField("username", userInput, "Enter username", {200, 30}, style);

Row

Arranges child widgets horizontally in a row.

Widget Row(RowArgs args = {});
Parameters
args: RowArgs struct containing configuration

RowArgs structure:

struct RowArgs {
    MainAxisAlignment mainAlign{};
    CrossAxisAlignment crossAlign{};
    int spacing = 0;
    std::vector<Widget> children{};
    ScrollBehavior scroll = ScrollBehavior::None;
    ScrollAxis axis = ScrollAxis::Horizontal;
    std::string id = "";
    float expandX = 0.0f;
    float expandY = 0.0f;
    bool autoSetupNav = false;
};

Header: nimble/widgets/row.cpp

Usage Example

auto row = Widgets::Row({
    .mainAlign = MainAxisAlignment::Start,
    .crossAlign = CrossAxisAlignment::Center,
    .spacing = 10,
    .children = {button1, button2, button3}
});
