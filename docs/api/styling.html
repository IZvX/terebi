Styling API

WidgetStyle

The core styling structure for widgets, controlling appearance and layout properties.

WidgetStyle

Structure containing all visual and layout styling properties for widgets.

struct WidgetStyle {
    SDL_Color color = {0, 0, 0, 0};
    Gradient gradient;
    int radius = 0;
    int borderWidth = 0;
    Vector2 position = {0, 0};
    bool positionChangesBounds = false;
    Vector2 padding = {0, 0};
    SDL_Color borderColor = {0, 0, 0, 0};
    Vector2 shadowOffset = {0, 0};
    SDL_Color shadowColor = {0, 0, 0, 0};
    int shadowSpread = 0;
    int shadowBlur = 0;
    ScrollbarStyle scrollbarStyle = g_GlobalScrollbarStyle;
};
PropertyTypeDescription
colorSDL_ColorBackground color (RGBA)
gradientGradientBackground gradient
radiusintBorder radius for rounded corners
borderWidthintBorder thickness
positionVector2Absolute positioning offset
positionChangesBoundsboolWhether position affects layout bounds
paddingVector2Internal padding
borderColorSDL_ColorBorder color
shadowOffsetVector2Shadow offset
shadowColorSDL_ColorShadow color
shadowSpreadintShadow spread radius
shadowBlurintShadow blur radius
scrollbarStyleScrollbarStyleScrollbar appearance

Header: nimble/utils/helpers.h

Usage Example

WidgetStyle style;
style.color = {255, 0, 0, 255}; // Red background
style.radius = 10; // Rounded corners
style.borderWidth = 2;
style.borderColor = {0, 0, 0, 255};

auto styledWidget = Widgets::RoundedBox(size, style, child);

Animation Modifiers

Widget methods for configuring animations.

OnHover(animId, duration, animFn, curve)

Configures hover animation.

Widget OnHover(const std::string &animId, float durationSec, std::function<void(Widget &, float)> animFn, std::function<float(float)> curveFn = Easing::EaseInOutQuad);

Header: nimble/widget.h

Usage Example

auto button = Widgets::Text("Hover me", font, color)
    .OnHover("hover", 0.3f, [](Widget &w, float t) {
        w.animateColor({255, 0, 0, 255}, t); // Animate to red
    });

Global Settings

Debug and development settings that affect all widgets.

GlobalSettings

Structure containing global developer settings.

struct GlobalSettings {
    bool showWidgetIds = false;
    bool showClipRects = false;
    bool showFlexWeights = false;
    bool showFocusLoop = false;
    bool highlightInputCapture = false;
    bool slowAnimations = false;
    bool paintFlashMode = false;
    bool showFPSOverlay = false;
    bool triggerStateReset = false;
};
